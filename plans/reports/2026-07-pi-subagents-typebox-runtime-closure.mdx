## Symptom

```txt
Cannot find module 'typebox/compile'
```

The async chain runner exited before its planner started. The require stack began at `pi-subagents/src/runs/shared/structured-output.ts` through bundled `jiti`.

## Context

- Environment: NixOS with Nix-packaged Pi `0.81.1`
- Extension: `pi-subagents` `0.35.1`
- Reported run: `74a24465-fb47-4eef-82b5-c8af7464cebe`
- Trigger: async chain path lazily imported structured-output validation
- Initial extension loading still passed because it did not exercise that lazy runner path

## Offending code

```nix title="packages/pi-subagents.nix" showLineNumbers startLineNumber=22 {4}
npmDepsHash = "sha256-VkexsgkRTUbMH5K8O513zdSCvItKEzGzqVZPSCxjjxQ=";
npmInstallFlags = [
  "--omit=dev"
  "--omit=peer" # Removed typebox from the isolated package closure.
];
```

Upstream declares `typebox` as an optional peer despite importing `typebox/compile` at runtime in runner-only modules. The package expression removed every peer and did not promote `typebox` into runtime dependencies.

## Root cause

Nix installs Pi and `pi-subagents` into separate immutable store outputs. Pi includes `typebox`, but Node/Jiti resolution from the `pi-subagents` package cannot traverse into Pi's separate `node_modules` tree. Packaging with `--omit=peer` therefore left no resolvable `typebox/compile` when the async runner loaded structured-output validation.

The existing load check only initialized the extension and listed models. It never imported the lazy structured-output module, so packaging appeared healthy.

## Fix

Pin `typebox` `1.3.8` as a runtime dependency inside the `pi-subagents` package closure and lockfile. Extend the package check to import the real TypeScript module through bundled `jiti` and validate a schema.

```diff
 p.dependencies.typebox = "1.3.8";
```

```diff
 test -d ${expectedSubagentsPath}/node_modules/typebox
+load("./src/runs/shared/structured-output.ts")
+validateStructuredOutputValue(schema, { ok: true })
```

The original isolated-module repro then passed without `NODE_PATH`. Focused `subagents-load` and full `nix flake check` also passed.

## Lesson

Optional-peer declarations do not prove a dependency is optional at runtime. For separately packaged Nix extensions, every dependency imported by a lazy execution path must either live in that extension's closure or be exercised through an explicit host-resolution contract. Load checks must cover lazy runner modules, not only extension startup.
