# Domain Docs

This repository uses a single domain context.

## Before exploring

- Read root `CONTEXT.md`.
- Read relevant ADRs under `docs/adr/` when present.
- Missing ADR files are normal; proceed silently.

## Vocabulary

Use canonical terms from `CONTEXT.md` in issues, plans, hypotheses, tests, and implementation. Avoid synonyms explicitly rejected by the glossary.

If a needed concept is absent, reconsider whether it belongs to this domain or note a real glossary gap for domain modeling.

## ADR conflicts

Surface conflicts with an existing ADR explicitly rather than silently overriding it.
